# LQ-GM-PID reproducibility package

This directory contains the complete code used for the numerical experiments and figures in the PRE manuscript **Analytic Bridge Diffusions for Controlled Path Generation**.

## Layout

- `experiments/exp_E1_corridor.ipynb` / `.py` — E1 density-level corridor optimization.
- `experiments/exp_E2_multi_entrance.ipynb` / `.py` — E2 finite empirical-source, sample-conditioned multi-entrance transport.
- `experiments/exp_H1_highdim_scaling.ipynb` / `.py` — H1 dimension/mode scaling and coarse-to-fine branching.
- `experiments/common.py` — utilities shared by the three experiments.
- `lqgm_pid/` — the minimal LQ-GM-PID implementation imported by these experiments.
- `figs/` — figures generated by the executed notebooks and used in the manuscript.
- `results/` — numerical summaries generated by the notebooks.

## Environment

A CPU-only Python environment is sufficient. Install the packages in `requirements.txt`, for example

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

The package was rerun in full with Python 3.13.5 and CPU PyTorch 2.10.0. The notebooks use fixed random seeds.

## Reproduce the paper results

Start Jupyter from this directory and run the three notebooks from top to bottom:

```bash
jupyter notebook
```

The notebooks write their figures to `figs/` and numerical summaries to `results/`. They do not require any downloaded datasets or external files.

The same computations can be run as Python scripts from this directory:

```bash
python -m experiments.exp_E1_corridor
python -m experiments.exp_E2_multi_entrance
python -m experiments.exp_H1_highdim_scaling
```

## Figures used in the manuscript

E1 produces `E1_comparison.pdf`, `E1_loss.pdf`, and `E1_params.pdf`. E2 produces `E2_comparison.pdf`, `E2_entrance_merging.pdf`, `E2_loss.pdf`, and `E2_params.pdf`. H1 produces `H1A_dimension_scaling.pdf`, `H1A_subspace_traces.pdf`, `H1B_mode_scaling.pdf`, `H1C_trunk_snapshots.pdf`, and `H1C_pca_snapshots.pdf`.
